# ระบบจัดการฟิตเนส

เว็บแอป Flask สำหรับจัดการข้อมูลฐานข้อมูล MySQL ของระบบฟิตเนส

## เมนู
- สมาชิก: ค้นหา เพิ่ม แก้ไข และลบสมาชิก
- คลาสฟิตเนส: จัดการคลาสและเทรนเนอร์ผู้สอน
- การจอง: จัดการการจองและสถานะ
- เทรนเนอร์: จัดการข้อมูลผู้ฝึกสอน
- อุปกรณ์: จัดการอุปกรณ์และจำนวน
- รายงาน: สรุปจำนวนข้อมูลและคลาสที่มีการจองมาก

## เริ่มใช้งานครั้งแรก
1. ติดตั้ง Python 3.10 ขึ้นไป
2. ติดตั้งไลบรารีด้วย `python -m pip install -r requirements.txt`
3. คัดลอก `.env.example` เป็น `.env` และกรอกค่าการเชื่อมต่อ MySQL ในเครื่องนั้น
4. เปิดเว็บด้วย `python app.py` แล้วไปที่ `http://127.0.0.1:5000`

ไฟล์ `.env` มีรหัสผ่านและถูกยกเว้นจาก Git ด้วย `.gitignore` ห้าม commit หรือแชร์ไฟล์นี้ แต่ละเครื่องต้องตั้งค่า `.env` ของตัวเอง
